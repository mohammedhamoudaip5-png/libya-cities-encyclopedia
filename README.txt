طريقة التركيب
1) افتح index.html عندك وابحث عن السطر الأخير قبل </body> :
   <script src="cities.js"></script><script src="app.js"></script>
   وغيّره إلى:
   <script src="cities.js"></script><script src="images-patch.js"></script><script src="app.js"></script>
2) انسخ app.js و images-patch.js ومجلد assets بجانب index.html (ادمج assets مع مجلدك الحالي، لا تحذفه).
   الصور الجديدة أسماؤها تبدأ بـ sample_ فلا تستبدل أي ملف عندك.
3) ارفع كل شيء إلى GitHub ثم فعّل Pages (Settings > Pages > Branch: main).
4) افتح الموقع، Ctrl+F5، ثم F12 > Console واكتب: [...MISSING_IMAGES]
   وابعث لي القائمة.

ما أُضيف
- مسلاتة: بطاقة + صورة في المعرض (لوحة جامع المجابرة).
- صبراتة: بطاقة (المسرح الروماني) + صورتان في المعرض.
- assets/unsorted: بقية الصور (13) بانتظار تحديد مدنها. راجع map.txt.

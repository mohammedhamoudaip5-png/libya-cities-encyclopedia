موسوعة المدن الليبية — حزمة تحديث الواجهة والصور للمدن العشرين
إعداد المهندس محمد عبدالمجيد حمودة

تتضمن الحزمة:
- index.html: الصفحة الرئيسية مع صورة العلم الجديدة وشاشة البداية.
- styles.css: تنسيقات الموقع والإضافات الجديدة.
- app.js: محرك المقالات والبحث والطقس واللغة، محفوظ من نسخة الموقع الأساسية.
- cities.js: فهرس المدن العشرين وربط صور البطاقات والمعارض.
- assets/municipalities/: صور المدن وفق مسارات ملف الصور المعتمد.
- images/flag.jpg: تصميم العلم الليبي الجديد.
- images/homepage-saraya-mizda.jpg: صورة واجهة الموقع الموجودة مسبقاً.

تنبيه بشأن اكتمال المقالات:
المقالات الموجودة في المصدر الأساسي حُفظت دون تغيير للمدن المتوفرة. ملف المصدر لا يحتوي حالياً على نصين موسوعيين كاملين للأصابعة والزنتان؛ لذلك أُدرجت بطاقتاهما وصورهما مع ملاحظة تحريرية واضحة بدلاً من اختلاق محتوى تاريخي لهما. يلزم إدراج النصين المعتمدين عند توفرهما.

خلفية الآية الكريمة:
لم تصل بعد الصورة المخصصة لخلفية الآية والنصوص المجاورة؛ لذلك لم أستبدل الخلفية الحالية بصورة غير معتمدة. يمكن دمجها فور إرسالها.

النشر:
1. فك ضغط الحزمة.
2. ارفع محتويات المجلد إلى جذر مستودع libya-cities-encyclopedia.
3. ارفع مجلدي assets وimages بالكامل.
4. اسمح باستبدال الملفات التي تحمل الاسم نفسه.
5. اضغط Commit changes وانتظر تحديث GitHub Pages.

لم يتم رفع الملفات إلى GitHub تلقائياً.

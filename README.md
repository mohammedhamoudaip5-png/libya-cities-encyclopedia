# موسوعة المدن الليبية - التحديث المعتمد (LIBYA-800-MH2026)

هذا المستودع يحتوي على الملفات المحدثة بالكامل لموسوعة المدن الليبية.

## 📌 مميزات التحديث:
1. **المدن الـ 21 بالكامل**: إدراج وتنسيق كافة المدن الـ 21 دون حذف أو تغيير.
2. **الصور المعتمدة**:
   - صورة مزدة القديمة.
   - صورة الرجبان البانورامية الثانية العريضة.
   - باقي الصور والمقالات المعتمدة سابقاً دون إضافة أي صور عشوائية.
3. **جاهزية GitHub**: هيكلية منظمة ومباشرة للرفع على GitHub Pages أو المستودع الرئيسي.

## 📁 الهيكلية:
- `index.html`: الواجهة الرئيسية للموسوعة.
- `css/style.css`: التصميم والتنسيق البصري.
- `js/main.js`: البرمجة وتوليد بطاقات المدن ديناميكياً.
- `data/cities.json`: البيانات الكاملة والمحدثة للمدن الـ 21.
- `assets/images/`: مجلد الصور المعتمدة.
